# Проекты и чаты Domovoy

## Рабочее пространство
Обычные чаты могут быть связаны с проектом. Проект предоставляет выбранную рабочую папку и разрешённые операции с файлами. Поведение выбора папки и доступность локальных операций зависят от платформы. Не считайте произвольный путь доступным, пока приложение не получило доступ к папке. База знаний проекта и пользовательские файлы не являются руководством продукта.

## Команды чата
Команда /help использует README/docs выбранного проекта и его Git-контекст. Команда /files предназначена для работы с файлами проекта по правилам доступа приложения. Эти команды относятся к обычному рабочему пространству. В поддержке ввод трактуется как вопрос консультанту; файловые и shell-инструменты не предоставляются.

## Обращения без проекта
Раздел «Поддержка» доступен без проекта. Один тикет связан с одним сохраняемым диалогом. При создании можно указать текущий проект как необязательную связь; это не даёт консультанту доступ к его файлам. Возврат из поддержки возвращает в прежнее рабочее пространство. Диалоги поддержки не отображаются в списке обычных чатов.
