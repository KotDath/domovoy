# MCP в Domovoy

## Подключения и разрешения
Раздел «MCP-подключения» показывает встроенные и пользовательские подключения, состояние и ошибки. Можно добавить внешний сервер Streamable HTTPS или, на поддерживаемой платформе, stdio. Сначала проверьте подключение; сохранённый endpoint не доказывает, что сервер сейчас доступен. Инструменты для обычного чата выбираются явно. Неизвестные или неразрешённые инструменты не получают доступ автоматически.

## Платформы
Сторонний stdio запускает внешний процесс и предлагается на Linux, Windows и macOS. На Android, iOS и web такой запуск недоступен. На Aurora сторонний stdio явно отключён: его работа не подтверждена. Для мобильного устройства используйте совместимый удалённый Streamable HTTPS сервер. Встроенные серверы запускаются самим приложением; на платформах без loopback HTTP применяется внутренний stream fallback. Наличие встроенного сервера не означает поддержку произвольной команды stdio.

## Поддержка
Встроенный сервер поддержки запускается автоматически и предоставляет только get_user_context и get_ticket. На Android и Linux используется настоящий локальный Streamable HTTP, привязанный к loopback с временной авторизацией. Сервер читает JSON-данные выбранного обращения и владельца. Приложение ограничивает доступ одним активным обращением; произвольный ID другого тикета не даёт доступа. В диалоге можно раскрыть аргументы и результат инструмента. Отсутствие успешного вызова или ошибка MCP не являются подтверждённым контекстом.
