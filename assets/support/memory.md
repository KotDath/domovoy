# Память и персонализация Domovoy

## Профиль ассистента
Профили задают персонализацию ассистента. Профиль не является учётной записью клиента и не меняет локального владельца обращений. Раздел профилей позволяет управлять персонализацией и интервью для её подготовки.

## Память
В обычном чате приложение может использовать рабочую и долговременную память с отдельными настройками чтения и инспектором. Извлечение памяти выполняется по правилам приложения и не гарантирует запоминания любого сообщения. Проверяйте сохранённые записи через интерфейс памяти; не считайте старый ответ ассистента достоверным фактом.

## Изоляция поддержки
Консультант поддержки не получает глобальную память, профили, другие диалоги или личные файлы. Для продолжения обращения ему доступны тема, описание, явный технический снимок и ограниченная история только этого тикета. История содержит пользовательский текст и прежние ответы как гипотезы; старые reasoning и tool payloads в неё не входят. Если подробность старой переписки не попала в ограниченную историю, повторите её в текущем вопросе без секретов.
