# Domovoy

Персональный ИИ-ассистент на Flutter с потоковыми ответами, сохраняемой историей
и подключением LLM через API. Эта ветка содержит результат отдельного учебного задания.

## Итог задания 9 — сжатие истории

Два независимых диалога выполняют одинаковые 14 запросов на DeepSeek Flash:
контроль отправляет полную историю, второй режим заменяет старую часть summary.
Отдельные классы триггера и компактора запускают сжатие после каждых 10 новых
сообщений пользователя и ассистента, сохраняя последние две пары как есть.
Summary хранится отдельно от исходного хвоста, используется в следующих запросах
и восстанавливается вместе с прогрессом после перезапуска.

### Результат эксперимента

Итоговый реальный прогон 13 сентября 2026 года:

| Режим | Вызовы API | Input | Output | Overall | Факты |
| --- | ---: | ---: | ---: | ---: | ---: |
| Полная история | 14 | 22906 | 1570 | 24476 | 8/8 |
| Ответы в режиме summary | 14 | 18080 | 1983 | 20063 | 8/8 |
| Создание двух summary | 2 | 3380 | 793 | 4173 | — |
| Summary, все вызовы вместе | 16 | 21460 | 2776 | 24236 | 8/8 |

С учётом создания summary расход меньше на 240 токенов, около 1%.
Input последнего запроса сократился с 3692 до 2710, на 26,6%.
Оба итоговых ответа сохранили восемь проверяемых фактов, включая обновлённый
бюджет 150000. Reload восстановил 14 шагов, summary, ответы и API-суммы.
Все 468 тестов прошли; анализ и сборки Linux/web успешны.

Экономия относится к этому прогону: на более коротком промежуточном сценарии
summary расходовал больше токенов, а первоначальная инструкция теряла факт.
В итоговом варианте уточнены правила сохранения решений и переноса прежнего summary.
Это сравнение токенов, а не денежной стоимости с учётом тарифов кэша.

### Запуск и видео

```sh
flutter run -d linux -t lib/day09_main.dart
```

Настройте ключ DeepSeek. «Следующий шаг» позволяет показать первое summary после
пятой пары; «Запустить все 14» завершает сравнение. Покажите summary, исходный хвост,
два итоговых ответа, отдельный расход сжатия и восстановление после перезапуска.
[Полный сценарий и история экспериментов](docs/day09-demo.md).
Видео не записано; подготовлены код и воспроизводимый сценарий.
Изменения задания находятся только в ветке `codex/day-09` и не включены в main.

## Linux development

The application stores an optional DeepSeek API-key override with Secret
Service. Install the `libsecret` runtime and development packages before
building the Linux desktop app. On Debian and Ubuntu:

```sh
sudo apt install libsecret-1-0 libsecret-1-dev
```

At runtime, Domovoy first uses the API key saved in its settings and otherwise
falls back to the `DEEPSEEK_API_KEY` process environment variable.
