# Domovoy

Персональный ИИ-ассистент на Flutter с потоковыми ответами, сохраняемой историей
и подключением LLM через API. Эта ветка содержит результат отдельного учебного задания.

## Итог задания 10 — три стратегии контекста без summary

Реализованы переключатель стратегии, независимое пошаговое выполнение и общий
сценарий из 14 одинаковых запросов на DeepSeek Flash:

- Sliding Window отправляет последние две завершённые пары сообщений.
- Key-Value Facts добавляет к такому же окну отдельную карту восьми поддерживаемых
  фактов. Явные поля пользователя обновляются до генерации; новый бюджет заменяет старый.
- Branching сохраняет checkpoint после восьмого шага и создаёт независимые A/B
  с общей исходной историей. Каждая продолжает только собственный диалог.

Полная переписка остаётся видимой для сравнения. Истории, факты, выбранная
стратегия, активная ветка и учёт восстанавливаются после перезапуска.

### Результат эксперимента

Реальный ручной прогон 13 сентября 2026 года, по 14 вызовов на стратегию:

| Стратегия | Input | Output | Overall | Сохранённые факты |
| --- | ---: | ---: | ---: | ---: |
| Sliding Window | 9196 | 1407 | 10603 | 0/8 |
| Key-Value Facts | 11318 | 2000 | 13318 | 8/8 |
| Branching, основная история | 20275 | 1269 | 21544 | 8/8 |

Окно потратило меньше токенов, но ответило «неизвестно» на восемь старых решений.
Facts сохранил все решения, включая актуальный бюджет 150000, при меньшем расходе,
чем полная история. Полная ветка также сохранила все восемь фактов.

По удобству окно не требует настройки фактов, но теряет старые детали; facts
требует поддерживать структуру полей; ветки удобны для независимых вариантов,
но передают длинный контекст. Извлечение facts детерминированное и ограничено
явными полями сценария, это не универсальная семантическая память.

Дополнительные два вызова в A дали 3090 input / 49 output / 3139 overall:
ветка запомнила лист ожидания. В B — 3072 / 44 / 3116: семейные записи.
Решения не смешались; восемь унаследованных вызовов не начислялись повторно в
новый расход веток. Переключение A/B и reload сохранили ответы и суммы.
Отдельно проверено продвижение только выбранной стратегии и создание checkpoint
на её собственном восьмом шаге. Все 471 тест прошли, анализ и Linux/web сборки успешны.
Числа описывают один прогон и не гарантируют такое же качество на другой беседе.

### Запуск и видео

```sh
flutter run -d linux -t lib/day10_main.dart
```

Настройте ключ DeepSeek. Покажите шаг выбранной стратегии, затем «Все 14 шагов»
и сравнение ответов/токенов. Создайте разные решения через «Добавить в A/B»,
проверьте память веток и восстановление после перезапуска.
[Полный сценарий и результаты](docs/day10-demo.md).
Видео не записано; подготовлены код и воспроизводимый сценарий.
Изменения задания находятся только в ветке `codex/day-10` и не включены в main.

## Linux development

The application stores an optional DeepSeek API-key override with Secret
Service. Install the `libsecret` runtime and development packages before
building the Linux desktop app. On Debian and Ubuntu:

```sh
sudo apt install libsecret-1-0 libsecret-1-dev
```

At runtime, Domovoy first uses the API key saved in its settings and otherwise
falls back to the `DEEPSEEK_API_KEY` process environment variable.
