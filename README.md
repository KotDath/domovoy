# Domovoy

Personal AI assistant built with Flutter.

## Linux development

The application stores an optional DeepSeek API-key override with Secret
Service. Install the `libsecret` runtime and development packages before
building the Linux desktop app. On Debian and Ubuntu:

```sh
sudo apt install libsecret-1-0 libsecret-1-dev
```

At runtime, Domovoy first uses the API key saved in its settings and otherwise
falls back to the `DEEPSEEK_API_KEY` process environment variable.

## День 2 — краткий отчёт

Один и тот же запрос сравнивался в двух вариантах: без ограничений и с явно
заданным контролем ответа через OpenAI-compatible Chat Completions API.

- **Формат ответа.** В нескольких прогонах модель корректно выполняла инструкции
  и возвращала требуемый JSON или Markdown. Для JSON использовались явный
  контракт и `response_format=json_object`. Даже при стабильных результатах
  валидатор полезен: он обнаруживает неверную структуру или отсутствующие поля и
  позволяет выполнить один ограниченный запрос на исправление.
- **Длина ответа.** В нескольких прогонах модель соблюдала инструкцию по
  максимальному количеству символов. Такая инструкция остаётся мягким
  ограничением, поэтому проверка фактической длины защищает от непредвиденного
  результата. Параметр `max_tokens` задаёт жёсткий потолок API, но ограничивает
  токены, а не символы; при достижении потолка ответ может оборваться с причиной
  `length`.
- **Условие завершения.** В нескольких прогонах модель корректно завершала ответ
  по заданной stop sequence. API прекращает генерацию перед маркером и обычно не
  включает его в итоговый текст. Проверка причины завершения, наличия маркера и
  текста после него помогает заметить несовместимость провайдера или неожиданное
  поведение модели.

**Вывод.** Чем точнее формат, длина и условие завершения заданы одновременно в
инструкции и параметрах API, тем предсказуемее ответ. Однако генерация остаётся
вероятностной: API-контроль следует дополнять локальными валидаторами, а не
считать один удачный прогон гарантией корректности.
