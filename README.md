# Domovoy

Персональный ИИ-ассистент на Flutter с потоковыми ответами, сохраняемой историей
и подключением LLM через API. Эта ветка содержит результат отдельного учебного задания.

## Итог задания 7 — сохранение контекста

История сообщений сохраняется в JSONL. При новом запуске runtime восстанавливает
сессию и передаёт прошлые сообщения в следующий запрос. Сохраняются также выбор
модели и учёт токенов. Пространство идентификаторов нового runtime исключает
коллизии при добавлении сообщений к восстановленной истории.

### Результат проверки

13 сентября 2026 года live-тест DeepSeek сохранил сессию, создал новый production
runtime, загрузил JSONL и продолжил диалог. Ответ сохранил название «Север» и
бюджет 150000. API usage после восстановления: 86 input / 17 output / 103 overall;
накопленный расход совпал с суммой физических вызовов.

В ручной браузерной проверке после перезагрузки сохранились история и факты
проекта. Дополнительный прогон восстановленной legacy-сессии вернул название
«Север», бюджет 150000 и срок 15 ноября; расход нового ответа — 156 / 15 / 171.
Повторная перезагрузка сохранила результат и счётчики. Общий набор: 464 теста прошли.
Ручная проверка использовала reload браузера; отдельный live-тест проверил новый
runtime и файловую JSONL-историю.

## Linux development

The application stores an optional DeepSeek API-key override with Secret
Service. Install the `libsecret` runtime and development packages before
building the Linux desktop app. On Debian and Ubuntu:

```sh
sudo apt install libsecret-1-0 libsecret-1-dev
```

At runtime, Domovoy first uses the API key saved in its settings and otherwise
falls back to the `DEEPSEEK_API_KEY` process environment variable.
