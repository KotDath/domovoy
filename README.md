# Domovoy

Персональный ИИ-ассистент на Flutter с потоковыми ответами, сохраняемой историей и подключением LLM через API. Эта ветка содержит результат отдельного учебного задания.

## Итог задания 10 — три стратегии контекста без summary

Общий сценарий из 14 сообщений естественного языка проходит через DeepSeek Flash и реальный `AgentRuntime`. Стратегии получают одинаковые пользовательские сообщения:

- Sliding Window передаёт последние две завершённые пары.
- Key-Value Facts использует **второго агента памяти**: он получает актуальные факты, две последние пары с ID и новое сообщение, предлагает добавление/изменение/удаление фактов, после проверки обновление сохраняется до основного ответа. Основной агент получает актуальную память как данные и короткое окно.
- Branching передаёт полную историю своей ветви; после шага 8 доступны независимые A и B.

Модель, режим и уровень reasoning определены одной конфигурацией для обеих ролей Facts. По умолчанию это DeepSeek Flash с отключённым reasoning; отдельного более дешёвого режима для агента памяти нет. Экстрактор выбирает ключи динамически, хранит ссылки на пользовательские сообщения-источники, сохраняет подтверждённые решения и не должен считать вопрос или гипотезу договорённостью. Его ответ проверяется до применения; при невалидном формате возможен один дополнительный вызов исправления. Повтор основного ответа после сбоя не запускает уже успешно применённое извлечение.

Интерфейс показывает полную историю, текущие факты, изменения и источники, свободный ввод, отдельный и общий расход/время ролей, результаты стратегий и физический ledger. Все числа токенов берутся только из API. Состояние хранится между перезапусками; прежний формат детерминированных facts явно сбрасывается как несовместимый.

Реальный прогон 13 сентября 2026 года: одинаковые 14 естественных сообщений,

Агент памяти сохранил 40 активных фактов, заменил бюджет на 150000, удалил
отменённое название отчёта «Тетрадь» и не включил идею голосовой записи в активные
требования. В расход вошёл один дополнительный вызов исправления результата.
**Экономии токенов нет: Facts примерно в 3,28 раза дороже полной истории.**
Сумма времени вызовов: окно 21,928 с, Facts 56,011 с (26,014 с ответы + 29,997 с
память), полная история 25,295 с. Это локальное время одного прогона, не
воспроизводимый бенчмарк задержки и не API-метрика.

Окно проще и дешевле, но теряет старые решения. Facts автоматически извлекает
решения из обычных фраз и делает их проверяемыми по источникам; это требует
дополнительных вызовов и не исключает ошибок модели. Полная история сохранила
факты без извлечения, а ветки удобны для независимых вариантов.
Ветка A назвала только лист ожидания (два новых вызова, 4255 токенов),
B — только семейные записи (два новых вызова, 4201 токен).

### Запуск

```sh
flutter run -d linux -t lib/day10_main.dart
```

Настройте ключ DeepSeek. Для видео покажите свободный ввод с естественным исправлением факта, изменения с источниками и отдельный расход двух ролей. Затем сбросьте сценарий, запустите все 14 шагов, сравните ответы и расходы, создайте A/B и перезапустите приложение. Изменения задания находятся только в ветке `codex/day-10`, не в main.

## Linux development

The application stores an optional DeepSeek API-key override with Secret
Service. Install the `libsecret` runtime and development packages before
building the Linux desktop app. On Debian and Ubuntu:

```sh
sudo apt install libsecret-1-0 libsecret-1-dev
```

At runtime, Domovoy first uses the API key saved in its settings and otherwise
falls back to the `DEEPSEEK_API_KEY` process environment variable.
