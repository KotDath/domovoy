## Why

Day 3 needs a repeatable way to compare four prompting strategies on exactly one analytical problem and decide which answer is most accurate without conflating prompt technique with the provider's native thinking mode. A dedicated reasoning-strategy laboratory makes every request, intermediate meta-prompt, result, cost, and evaluation visible for a Linux desktop video.

## What Changes

- Add a Day 3 laboratory screen with four independently runnable strategies: direct answer, explicit step-by-step instruction, generated solver prompt followed by execution, and a group of analyst/engineer/critic experts.
- Use a four-house logic-grid puzzle with a verified unique solution as the editable shared task and explicitly disable DeepSeek native reasoning for every Day 3 request so the comparison isolates prompt-level reasoning.
- Stream each result independently, preserve partial output and sanitized failures, expose the generated prompt used by the meta-prompt strategy, and label the real API-call cost of each strategy.
- Add a deterministic local reference solver that exhaustively checks all resident, drink, and pet permutations and proves that the preset has exactly one assignment.
- Show the unique reference grid beside transparent manual accuracy ratings so the user can mark each natural-language response correct, partial, or incorrect and select the most accurate strategy without an LLM-as-judge.
- Add deterministic unit, controller, widget, and opt-in live-provider integration coverage plus a credential-safe Linux demonstration checklist. The recorded video remains a manual deliverable.

## Capabilities

### New Capabilities

- `reasoning-strategy-comparison`: Four-way prompt-strategy execution, meta-prompt chaining, expert-role prompting, a locally verified unique puzzle reference, and transparent comparison on a dedicated Day 3 screen.

### Modified Capabilities

- `prompt-workspace`: Extend application navigation with a distinct Day 3 destination while preserving the Day 1 prompt workspace and Day 2 response laboratory.

## Impact

- Adds provider-neutral strategy orchestration on top of the existing one-shot `Agent` stream without conversation history or an agent framework.
- Expands Flutter navigation and settings-independent experiment state while retaining the direct OpenAI-compatible DeepSeek Chat Completions adapter.
- Adds a pure-Dart logic-grid model/solver, manual evaluation state, strategy controllers, responsive UI, automated tests, an opt-in live smoke test, and Day 3 demo documentation.
- Day 3 uses additional paid calls: one each for direct, step-by-step, and expert-group strategies, plus two for meta-prompt generation and execution.
