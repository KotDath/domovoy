# MCP: задачи дней 16–20

Статус: задачи зафиксированы, реализация не начата. Для каждого дня результат
сдаётся в формате **видео + код**.

## День 16. Подключение MCP

- [ ] Выбрать MCP SDK/клиент и сервер для проверки соединения.
- [ ] Реализовать минимальное подключение к MCP-серверу.
- [ ] Получить и вывести список доступных инструментов.
- [ ] Проверить успешное соединение и корректность списка.
- [ ] Подготовить видео и код.

**Результат:** код, который подключается к MCP и выводит список инструментов.

Видео из задания: https://disk.yandex.ru/i/t-0o7WGK8e5x3Q

## День 17. Первый инструмент MCP

- [ ] Реализовать свой MCP-сервер вокруг выбранного API (например, Яндекс.Трекер,
  Git, CRM или mock API).
- [ ] Зарегистрировать инструмент, описать входные параметры и возвращаемый
  результат.
- [ ] Подключить инструмент к агенту Domovoy.
- [ ] Вызвать инструмент из приложения и использовать результат в ответе агента.
- [ ] Подготовить видео и код.

**Результат:** агент вызывает MCP-инструмент и получает его результат.

## День 18. Планировщик и фоновые задачи

- [ ] Сохранять задания и результаты в JSON или SQLite.

- [ ] Подготовить видео и код.

- [ ] Проверить порядок вызовов и передачу данных между инструментами.
- [ ] Подготовить видео и код.
