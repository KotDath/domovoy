# День 10: окно, агент памяти и ветки

Эта ветка сравнивает три стратегии на одинаковых 14 пользовательских сообщениях из `assets/day10_scenario.json`. Каждый основной ответ идёт через DeepSeek Flash и `AgentRuntime`. Стратегия Facts делает перед ответом **отдельный LLM-вызов** через тот же runtime, ту же модель и ту же конфигурацию reasoning. По умолчанию reasoning выключен у обеих ролей. Агент памяти выбирает динамические ключи, предлагает add/update/delete и указывает ID сообщения-источника. Код проверяет операции и сохраняет всю транзакцию до ответа. При ошибке формата он делает максимум один дополнительный вызов исправления, затем останавливает шаг. Вся физическая стоимость включена в таблицу.

## Запуск

```sh
flutter run -d linux -t lib/day10_main.dart
```

Ключ DeepSeek берётся из обычного безопасного хранилища или переменной окружения `DEEPSEEK_API_KEY`. Для браузера ключ остаётся на хосте локального релея:

```sh
flutter build web --no-web-resources-cdn --target lib/day10_web_main.dart --output /tmp/domovoy-day10-memory-web
python3 tool/live_proxy.py --directory /tmp/domovoy-day10-memory-web --port 8772
```

Перед запуском релея передайте ему `DEEPSEEK_API_KEY` через окружение терминала. Откройте `http://localhost:8772`. Не помещайте секрет в сборку браузера и кадр видео. Реальная проверка 14 шагов отправляет примерно 56 вызовов: 14 для Sliding, 14 для Branching, 14 основных и 14 извлечений для Facts; невалидный результат может добавить один платный вызов исправления. A/B добавляют четыре вызова.

## Короткий сценарий для видео

1. Начните с пустого состояния. Выберите «Факты» и свободным вводом сообщите обычной фразой название проекта, бюджет и срок без `Ключ: значение`.
2. Напишите вопрос о возможной функции, явно не утверждая её. Посмотрите, что в активной памяти нет принятого решения. Измените бюджет и отмените ранее согласованный срок обычными словами. Покажите `update`/`delete`, значения до/после, источники и расход агента памяти.
3. Добавьте два нейтральных сообщения, чтобы исходное выпало из двухпарного окна, затем спросите основные решения. Перезагрузите страницу: факты, edits, usage и выбор стратегии должны сохраниться.
4. Нажмите «Сбросить», затем «Все 14 шагов». Это независимый чистый эксперимент; свободные сообщения не входят в общий сценарий. Сравните итоговые ответы с восемью контрольными фактами, исходные API input/output/cache/overall, время и отдельную цену роли памяти. Скользящее окно передаёт только последние две пары; Facts — две пары плюс факты; Branching — полную собственную историю.
5. После восьмого шага Branching открываются A/B. Добавьте лист ожидания только в A, семейные записи только в B, выполните проверки, переключитесь и перезагрузите страницу. В расходе A/B указаны только новые вызовы, но в каждом новом запросе input за унаследованный контекст учитывается по API.

Если версия 1 демо с фиксированным парсером уже сохраняла состояние, приложение явно начинает новый сценарий; старые данные не интерпретируются как факты с источниками.

## Что проверять и как трактовать результат

Восемь контрольных фактов исходного задания: проект «Север», действующий бюджет `150000`, срок 15 ноября, уведомления только email, хранение данных в России, отсутствие онлайн-оплаты, длительность 45 минут, отмена не позднее трёх часов. Это **рубрика для чтения итогового ответа**, не список ключей для агента памяти: его инструкция содержит только общие категории целей, ограничений, предпочтений и решений. Сам сценарий также включает факт вне этой восьмёрки, отмену названия внутреннего отчёта и неподтверждённую идею голосовой записи. Нужно смотреть фактические следы: сохранил ли агент верное, удалил ли отменённое, не принял ли гипотезу.

| Стратегия | Контекст запроса | Особенность расхода |
| --- | --- | --- |
| Sliding | Две последние завершённые пары | Только основной агент |
| Facts | Актуальные факты как данные и две пары | Основной + извлечение + возможное исправление |
| Branching | Полная история собственной ветви | Только основной агент; A/B считают новый расход отдельно |

Наблюдаемые числа у разных повторов могут меняться. `—` в ledger значит, что API не прислал метрику; частичный subtotal помечен `+`. Время измерено локальным stopwatch вокруг вызова роли; это не API-метрика. Не выдавайте его за оплаченный расход.

### Предыдущий эксперимент, до агента памяти

13 сентября 2026 года версия с детерминированным парсером дала 10 603 токена у Sliding (0/8 фактов), 13 318 у Facts (8/8) и 21 544 у Branching (8/8). У прежних Facts **не было второго агента и его стоимости**. Эти числа оставлены как исторический baseline, не результат текущего кода. Это исторические значения, не стоимость текущей реализации.

Финальный автоматический набор: 477 тестов прошли. Видео не записано; эти действия предназначены для его записи.


### Реальный эксперимент с агентом памяти

13 сентября 2026 года финальный 14-шаговый прогон выполнен через production
AgentRuntime инструментом `tool/live_day10_memory_test.dart`. Общая конфигурация
двух ролей: DeepSeek Flash, reasoning disabled, model-default effort,
maxOutputTokens 1536. Сценарий находится в `assets/day10_scenario.json`.

| Стратегия / роль | Вызовы | Input | Output | Overall | Cache read | Время вызовов, мс |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Sliding | 14 | 10409 | 2021 | 12430 | 768 | 21928 |
| Facts, main | 14 | 28027 | 2105 | 30132 | 11904 | 26014 |
| Facts, memory | 15 | 58857 | 3542 | 62399 | 36096 | 29997 |
| Facts, сумма | 29 | 86884 | 5647 | 92531 | 48000 | 56011 |
| Branching | 14 | 26280 | 1972 | 28252 | 23040 | 25295 |

Итоговые ответы Facts и Branching сохранили 8/8 проверяемых фактов; Sliding
пометил все восемь как неизвестные. Память содержит 40 активных записей. В ней
бюджет обновлён до 150000, отменённое название внутреннего отчёта «Тетрадь»
имеет операцию delete и не осталось активным названием, голосовая идея не
попала в активные факты. Это чтение реальных результатов, не автооценка по
предзаполненной памяти. Ссылки на источники ведут к сообщениям в том же артефакте.

15 вызовов памяти включают один вызов исправления; его расход не скрыт.
В этом сценарии Facts дороже полной истории примерно в 3,28 раза, даже основной
агент Facts получил больше input из-за подробной карты. Извлечение повысило
прозрачность памяти, но не дало экономии токенов. Время — сумма stopwatch вокруг
вызовов, включая ожидание и поток; это не измеренная API цена или гарантия задержки.

A после checkpoint сделала два новых вызова: 4191 input / 64 output / 4255 overall,
и назвала только лист ожидания. B: 4157 / 44 / 4201, назвала только семейные записи.
В каждой исключены из нового расхода восемь исторических вызовов родителя;
повторная передача префикса в новых запросах при этом входит в API input.

Полный сохранённый результат: [JSON evidence](evidence/day10-memory-live.json).
Для самостоятельного платного повтора с ключом в окружении:

```sh
flutter test --no-pub tool/live_day10_memory_test.dart --reporter expanded
```

Runner сбрасывает собственное тестовое состояние и пишет данные после каждого
шага в `/tmp/domovoy-evidence/day10-memory-live.json`. Сохранённый в репозитории
артефакт автоматически не перезаписывается.

Первый пробный прогон более общей инструкции памяти сохранил 76 активных записей,
включая временные просьбы о формате ответа. Facts потратил 102957 токенов против
28097 полной истории, оба ответа сохранили 8/8 фактов. После уточнения отбора
долговременных решений проведён отдельный финальный прогон выше. Числа разных
прогонов не смешиваются. Дополнительные проверяемые факты выбирает модель, поэтому
ни число записей, ни точные расходы, ни качество не гарантированы для следующего запуска.


### Ручная проверка свободного ввода и перезапуска

В финальной браузерной сборке выполнены семь собственных сообщений, не входящих
в общий сценарий. Обычная фраза задала проект «Ладога», девяносто тысяч рублей
и второе декабря. Гипотеза о голосовой записи не стала активным требованием.
Следующая фраза обновила бюджет до 110000, отмена срока создала delete. После
двух нейтральных сообщений и reload агент ответил: «Название проекта: „Ладога“.
Бюджет: 110 000 рублей. Согласованный срок: неизвестно. Статус идеи голосовой
записи: неизвестно». Он сохранил действующие факты и не выдал идею за решение;
статус самой неутверждённой идеи после выхода из окна уже неизвестен.

После шестого сообщения reload сохранил выбранную стратегию Facts, шесть пар,
12 вызовов и 7603 токена. После седьмого общий расход составил 8833:
основной агент 1779 input / 171 output / 1950 overall, память 6599 / 284 / 6883.
В раскрываемой истории видны оригинальные фразы и ID, соответствующие источникам
фактов и операций. Sliding/Branching остались пустыми: свободный ввод продвигал
только выбранную стратегию.
